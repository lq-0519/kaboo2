# Codex Quota

一个常驻 macOS 菜单栏的 Codex 订阅额度监控工具。无需反复打开 Codex 或账号页面，就能看到还剩多少额度、什么时候恢复，以及当前可用的重置卡。

仓库目录名为 `kaboo2`，应用名称为 **Codex Quota**。

## 主要功能

- 同时显示 5 小时和 7 天额度的剩余百分比及恢复倒计时。
- 点击菜单栏查看额度进度、重置时间、数据更新时间和重置卡明细。
- 查询可用重置卡数量及服务返回的有效期；工具仅查询，不使用重置卡。
- 自定义额度刷新间隔、重置卡刷新间隔、菜单栏时间显示方式、字体和动态颜色。
- 可选的额度恢复通知，在检测到新额度周期后提醒。
- 可选的额度恢复自动问候，通过 Codex CLI 在后台发送一次“你好”。
- 支持登录后自动启动；暂时查询失败时保留最近有效数据并显示错误。

## 适合什么场景

经常使用 Codex，希望随时判断还能继续工作多久，或等待额度恢复后继续任务。菜单栏直接显示两个额度窗口，方便安排工作，无需频繁切换页面查看。

自动问候是独立的可选功能，默认关闭。开启后会消耗少量订阅额度；它不打开桌面聊天窗口，也不会修改你的代码项目。

## 环境要求

- macOS 13 或更新版本。
- Xcode Command Line Tools，使用 Swift 和系统框架，无第三方包依赖。
- 已通过 ChatGPT 订阅账号登录 Codex，并存在可读的本地 `auth.json`。
- 重置卡查询和自动问候需要可用的 Codex CLI，或应用内附带的兼容 CLI。

当前读取的是订阅账号的额度；仅使用 API Key 的登录方式不支持这类额度查询。默认认证文件为 `~/.codex/auth.json`，设置 `CODEX_HOME` 时改为读取该目录下的 `auth.json`。

## 构建与运行

在项目目录执行：

```bash
./build.sh
open "dist/Codex Quota.app"
```

脚本按当前 Mac 的架构编译，输出 `dist/Codex Quota.app`。可把应用放到一个长期固定的位置再开启登录自启动。

签名优先使用已有的 `InputHoldSwitcher Local Code Signing` 证书；也可指定自己的证书：

```bash
SIGNING_IDENTITY="你的代码签名证书名称" ./build.sh
```

没有匹配证书时，当前脚本会使用 ad-hoc 签名。

## 使用方法

1. 先确认 Codex 已登录订阅账号。
2. 启动应用，菜单栏显示 5 小时和 7 天剩余额度及恢复倒计时。
3. 点击菜单栏查看详细额度和重置卡；点击刷新按钮可立即查询。
4. 打开设置，按需选择菜单栏时间显示方式、调整刷新间隔或开启登录自启动。
5. 如需额度恢复通知，在设置中开启并允许 macOS 通知。
6. 如需自动问候，在设置中单独开启；“测试发送你好”会实际提交一次模型请求。

额度默认每 60 秒查询一次，允许设置为 10～86400 秒；重置卡默认每 5 分钟查询一次，允许设置为 1～60 分钟。菜单栏倒计时在本地更新，不会每次重绘都发起网络查询。

“显示 → 菜单栏时间”默认选择“距离重置”，沿用 `3h24`、`2d6` 的紧凑倒计时；7 天额度不足 1 天时显示小时和分钟。选择“下次重置时间”后，5 小时额度始终显示 24 小时制时分，例如 `14:30` 或 `2:25`；7 天额度今天重置时显示时分，明天及以后显示月/日，例如 `10/22`。日期按本地时区判断，跨午夜自动切换，选项保存后立即生效。

## 常见问题

**提示未检测到 Codex 登录？** 先在 Codex 中使用 ChatGPT 账号完成登录，确认认证文件路径与 `CODEX_HOME` 设置一致。

**提示未找到 Codex？** 将 Codex CLI 放到常见安装位置或 `PATH` 中。应用也会检查 Codex / ChatGPT 应用包内的 CLI。

**倒计时结束后没有立即恢复？** 倒计时来自上次服务返回的重置时间。实际剩余额度及恢复判断以新查询结果为准，可手动刷新。

**重置卡为空或无法读取？** 以当前账号和兼容 CLI 返回的结果为准；额度和重置卡分别查询，其中一项失败不会清空另一项。

**自动问候要求检查上次执行？** 通过设置里的执行日志核对结果，再确认继续，避免重复提交。

## 数据与兼容性

工具读取本地 Codex 认证信息，仅向代码中指定的 ChatGPT 服务查询额度；不会把登录文件复制到仓库。重置卡通过本地 Codex App Server 查询，自动问候通过 CLI 执行。

设置和执行状态保存在本机。自动问候状态位于 `~/Library/Application Support/CodexQuota/greetings.json`；设置中提供执行日志入口。额度查询使用临时网络会话，避免磁盘网络缓存。

额度服务及 App Server 协议可能随 Codex 更新变化，当前实现并非 OpenAI 官方产品。升级后出现查询错误时，需要核对接口和 CLI 的兼容性。
